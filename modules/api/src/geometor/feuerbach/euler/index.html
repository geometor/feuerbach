src.geometor.feuerbach.euler¶

Symbolic proofs and Euclidean construction for Euler’s 1765 memoir (E325) and Feuerbach (1822).

Implements:

  1. prove_euler_1765_identities(): 100% exact rational-function proofs in sympy over free side symbols \((a, b, c)\) for:

    • Euler’s six squared mutual center distances (§ 18, Formulas I–VI, p. 114),

    • Euler’s collinearity ratio \(EH = \frac{3}{2}EF\), \(FH = \frac{1}{2}EF\) (§ 16 & § 18),

    • Euler’s Stewart relation \(4GH^2 + 2EG^2 = 3EF^2 + 6FG^2\) (§ 18, p. 114),

    • Feuerbach’s tritangent & orthic identities (§§ 5, 28, 49–60, pp. 4–41), including the four nine-point tangency quadrances \(\overline{LS}^2 = (\frac{1}{2}R - r)^2\) and \(\overline{LS^{(k)}}^2 = (\frac{1}{2}R + r^{(k)})^2\) (§ 57, pp. 37–38) and the corrected centroid-orthocenter sums \(\sum \overline{OS_i}^2 = 16R(R - \rho)\) (§ 52) and \(9\sum \overline{GS_i}^2 = 16R(7R - \rho)\) (§ 60),

    evaluated concretely in exact sympy.Rational arithmetic on the canonical Heronian (15, 13, 14) triangle.

  2. solve_euler_reconstruction_cubic(): Exact symbolic solver for Euler’s inverse problem (§§ 19–24, pp. 114–118), recovering \(z^3 - pz^2 + qz - r = 0\) from the mutual quadrances of (E, F, G, H) and verifying Euler’s (5, 6, 7) test case.

  3. construct_euler_1765_centers(): Pure compass-and-straightedge Model proposition constructing E = X(4), F = X(2), G = X(1), H = X(3), the circumcircle, the incircle, and the Euler line [H E].

src.geometor.feuerbach.euler.solve_euler_reconstruction_cubic(ef_sq: sympy.Rational, fg_sq: sympy.Rational, gh_sq: sympy.Rational, eg_sq: sympy.Rational | None = None) → tuple[sympy.Rational, sympy.Rational, sympy.Rational, sympy.Expr, tuple[sympy.Rational, ...]]¶

Recover \((p, q, r)\) and the side-length cubic \(z^3 - pz^2 + qz - r = 0\).

Follows Euler’s E325 §§ 19–22 (pp. 114–117):

  • If eg_sq is omitted, determines \(EG^2\) from Stewart’s collinearity law \(4GH^2 + 2EG^2 = 3EF^2 + 6FG^2\).

  • Sets \(f = EG^2 - GH^2\), \(g = FG^2 - EF^2\), \(h = \frac{9}{4}EF^2 - 3GH^2\), recovers \(Q = r/p\), \(R = r^2/(4A^2) = 4(GH^2 + Q)\), \(P = p^2\), \(q\), and \(r = pQ\).

Parameters:

  • ef_sq – Exact squared distance \(EF^2 = Q(X_4, X_2)\).

  • fg_sq – Exact squared distance \(FG^2 = Q(X_2, X_1)\).

  • gh_sq – Exact squared distance \(GH^2 = Q(X_3, X_1)\).

  • eg_sq – Optional \(EG^2 = Q(X_4, X_1)\); verified against Stewart’s law if given.

Returns:

Tuple (p, q, r, cubic_expr, sorted_rational_roots).

Raises:

ValueError – If eg_sq violates Euler’s collinearity relation or \(P = p^2\) is not a positive rational square.

src.geometor.feuerbach.euler.construct_euler_1765_centers(model: geometor.model.Model | None = None) → EulerCentersResult¶

Construct Euler’s four centers (E, F, G, H) and prove his 1765 collinearity theorems.

Uses the canonical acute scalene Heronian triangle A = (0, 0), B = (14, 0), C = (5, 12) with integer sides a = 15, b = 13, c = 14 so every classical center lands on exact rational coordinates over \(\mathbb{Q}\).

Parameters:

model – Optional existing Model. When None, creates a new model with auto_intersect=False.

Returns:

EulerCentersResult containing the model and constructed geometric entities.

Raises:

ProofAssertionError – If any deductive concurrency, collinearity, or metric assertion fails.
