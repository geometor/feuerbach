src.geometor.feuerbach.render¶

Theme-adaptive .euclid-graphic SVG exporter for Euler (1765) and Feuerbach (1822).

Generates clean, standards-compliant <svg class="euclid-graphic"> diagrams directly from exact Model constructions. Every geometric element carries:

  • 3-vertex midpoint paths M x1 y1 L mx my L x2 y2 supporting #geom-tick-1..3 equality ticks,

  • Canonical data-ref tokens (A, X5, X11, / A B /, [ X3 X4 ], ( X5 H1 ), < A B C >) compatible with geometor_interactive.js,

  • Presentation attributes bound to var(--geom-fg), var(--geom-accent), var(--geom-assert), and var(--geom-coincide) so both standalone SVGs and publish inline .. picture:: book figures adapt seamlessly to light and dark themes.
