§§ 3–7: §§ 3–7: Symmetric Polynomial Laws Among the Four Tritangent Radii — Summary
===================================================================================

.. rubric:: Mathematical Overview — *§§. 3–7. Symmetrische Relationen unter den Halbmessern r, r', r'', r'''*

Section Overview
----------------

* **§§ 3–7 — Elementary Symmetric Polynomials of the Radii**:
  - **§ 3**: :math:`r'r'' + r'r''' + r''r''' = s^2 = \frac{1}{4}(a + b + c)^2`.
  - **§ 4**: :math:`r'r''r''' = r(r'r'' + r'r''' + r''r''') = s\Delta \iff \frac{1}{r'} + \frac{1}{r''} + \frac{1}{r'''} = \frac{1}{r}`.
  - **§ 5**: :math:`r' + r'' + r''' - r = 4R` (sum of signed exradii equals four circumradii).
  - **§ 6**: :math:`\sum_{i < j} r_i r_j = ab + ac + bc`.
  - **§ 7**: :math:`r'^2 + r''^2 + r'''^2 = (r + 4R)^2 - 2s^2`.
