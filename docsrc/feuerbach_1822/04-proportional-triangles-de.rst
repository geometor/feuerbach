§§. 61–62. Mittlere Proportionalität des Dreiecks MNP
-----------------------------------------------------

Es seyen im Dreieck :math:`ABC`, :math:`M, N, P` die Fußpunkte der aus den Winkelpunkten :math:`A, B, C` auf die gegenüberliegenden Seiten gefällten Senkrechten, deren Durchschnittspunkt :math:`O`; ferner im Dreieck :math:`MNP`, :math:`d, e, f` die Berührungspunkte seines innerhalb berührenden Kreises, so wie :math:`d', e', f'` die Berührungspunkte seines ausserhalb berührenden in der Ebene des Winkels :math:`PMN` befindlichen Kreises (*Fig. 8*).

Weil (§. 26.) der Halbmesser des um das Dreieck :math:`MNP` beschriebenen Kreises gleich :math:`\frac{1}{2}R`, so ist (§. 8.) :math:`\triangle def : \triangle MNP = \rho : R`, und, da (§. 25.) :math:`\triangle MNP : \Delta = \rho : R`, so folgt:

.. math::

   \triangle def : \triangle MNP = \triangle MNP : \Delta

(und für das bei :math:`A` stumpfwinklige Dreieck :math:`\triangle d'e'f' : \triangle MNP = \triangle MNP : \Delta`), woher man den Satz erhält:

*Das Dreieck* :math:`MNP` *ist das mittlere geometrische Proportional Dreieck zwischen dem Dreieck* :math:`ABC` *und jenem, welches die Berührungspunkte desjenigen die drei Seiten des Dreiecks* :math:`MNP` *berührenden Kreises bilden, dessen Mittelpunkt jedesmal in den Durchschnittspunkt der Perpendikel des Dreiecks* :math:`ABC` *fällt.*

Zugleich folgt nach ähnlicher Schlußfolge: *Jedes Dreieck ist selbst das mittlere geometrische Proportional-Dreieck zwischen dem Dreieck, welches die Berührungspunkte irgend eines seiner vier berührenden Kreise bilden, und demjenigen, welches die Mittelpunkte der drei übrigen bestimmen.* Ferner ist (§. 62.):

.. math::

   de + df + ef : MN + MP + NP = \rho : r.

§§. 63–65. Die Fußpunktdreiecke μ, μ', μ'', μ''' in den vier Berührungsdreiecken
--------------------------------------------------------------------------------

* **§. 63. (S. 43–44)** Bezeichnet man gleichwie in §. 8. durch :math:`\delta, \delta', \delta'', \delta'''` die Inhalte derjenigen Dreiecke, welche durch die Berührungspunkte der Kreise von den Halbmessern :math:`r, r', r'', r'''` bestimmt werden; ferner durch :math:`\mu, \mu', \mu'', \mu'''` die Inhalte derjenigen Dreiecke, welche die Fußpunkte der Perpendikel in den Dreiecken :math:`\delta, \delta', \delta'', \delta'''` bilden (*Fig. 9–10*), so ergeben sich folgende Proportionen:

  .. math::

     \mu : \delta = \delta : \Delta, \qquad
     \mu' : \delta' = \delta' : \Delta, \qquad
     \mu'' : \delta'' = \delta'' : \Delta, \qquad
     \mu''' : \delta''' = \delta''' : \Delta,

  wobei die Dreiecke :math:`\mu, \mu', \mu'', \mu''', ABC` alle einander ähnlich also liegen, daß ihre den gleichen Winkeln gegenüberliegenden Seiten mit einander parallel gehn.

* **§. 64. (S. 44)** Wegen :math:`\mu + \mu' + \mu'' + \mu''' = \frac{\Delta}{4R^2}(r^2 + r'^2 + r''^2 + r'''^2)` und (§. 28.) :math:`r^2 + r'^2 + r''^2 + r'''^2 = 4R(2R - \rho)` folgt für das spitzwinklige Dreieck:

  .. math::

     \mu + \mu' + \mu'' + \mu''' + \triangle MNP = 2\Delta

  (und für das stumpfwinklige :math:`\mu + \mu' + \mu'' + \mu''' - \triangle MNP = 2\Delta`).

* **§. 65. (S. 44)** Da :math:`mn = r\sin\gamma`, :math:`mp = r\sin\beta`, :math:`np = r\sin\alpha` und :math:`\sin\alpha + \sin\beta + \sin\gamma = \frac{\Delta}{rR}`, so folgt mit (§. 19.) :math:`MN + MP + NP = \frac{2\Delta}{R}`:

  .. math::

     mn + mp + np = \frac{1}{2}(MN + MP + NP).

§§. 71–87. Inkreise O', O'', O''' der Eckdreiecke und Höhenschnitt S von ΔO'O''O'''
-----------------------------------------------------------------------------------

* **§§. 71–73. (S. 48)** Bedeutet :math:`\mathfrak{r} = \frac{r^2}{2R}` den Inkreishalbmesser von :math:`\triangle mnp`, und beschreibt man in die Dreiecke :math:`ANP, BMP, CMN` Kreise (*Fig. 11*) mit Mittelpunkten :math:`O', O'', O'''` und Halbmessern :math:`\rho' = r\cos\alpha`, :math:`\rho'' = r\cos\beta`, :math:`\rho''' = r\cos\gamma`, so folgt:

  .. math::

     OM + ON + OP &= \rho + 2(r + \mathfrak{r}), \\
     \rho' + \rho'' + \rho''' &= r + 2\mathfrak{r}, \\
     OM + ON + OP &= r + \rho + \rho' + \rho'' + \rho'''.

.. folio:: §. 87.
   :page: 55

* **§. 87. (S. 55)** Die kongruenten Dreiecke :math:`DEF` und :math:`O'O''O'''` liegen also, daß ihre den gleichen Winkeln gegenüberliegenden Seiten mit einander parallel gehen, und die Mittelpunkte :math:`O', O'', O'''` der in :math:`ANP, BMP, CMN` beschriebenen Kreise sind zugleich die Durchschnittspunkte der Perpendikel in :math:`AEF, BDF, CDE`. Aus :math:`\overline{O'S}^2 = (SF - O'e)^2 + (AF - Ae)^2 = 4r^2\sin^2\frac{1}{2}\alpha` folgt:

  .. math::

     O'S = 2r\sin\frac{1}{2}\alpha = DJ, \qquad
     O''S = 2r\sin\frac{1}{2}\beta = EJ, \qquad
     O'''S = 2r\sin\frac{1}{2}\gamma = FJ.

  Da nun :math:`J` (§. 63.) der Durchschnittspunkt der Perpendikel im Dreieck :math:`DEF`, so ist auch :math:`S` der Durchschnittspunkt der Perpendikel im Dreieck :math:`O'O''O'''` und es ergiebt sich der Satz:

  **Der Mittelpunkt des in das Dreieck ABC beschriebenen Kreises ist zugleich der Durchschnittspunkt der Perpendikel im Dreieck O'O''O'''.**
