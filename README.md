## Mission

`geometor/feuerbach` is part of the interconnected [GEOMETOR](https://geometor.com) semantic digital archive. It liberates Karl Wilhelm Feuerbach's revolutionary 1822 monograph *Eigenschaften einiger merkwürdigen Punkte des geradlinigen Dreiecks* from isolated print bounds into addressable semantic units, synchronized reading tracks, calibrated theme-adaptive vector diagrams, primary-source folio provenance, and exact symbolic algebra across the GEOMETOR corpus.

## Books in This Archive
